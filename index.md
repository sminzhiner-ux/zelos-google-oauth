# Zelos Mail and Calendar

Zelos Mail and Calendar is a personal Google integration for an assistant running in a private Hermes Agent installation. It is used by the owner of the connected Google account; there is no public sign-up.

The assistant can help the owner with Gmail, Google Calendar, Drive, Docs, Sheets, and Contacts according to the permissions granted by the owner.
